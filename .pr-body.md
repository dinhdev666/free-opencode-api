fix(opencode): find the opencode binary on every platform

opencode's postinstall copies the platform binary to `node_modules/opencode-ai/bin/opencode.exe` on every platform, the `.exe` suffix included. The resolver looked for `bin/opencode` on POSIX, so on Linux it missed the package binary and fell back to the shell shim in node_modules/.bin, which starts differently.

The resolver now tries both names in the package directory first.

Also points the opencode workdir at /data in the container, so the snapshots opencode takes live on the volume instead of in the image layer.

Adds test/binary.test.mjs, which asserts the binary is found, is the real executable rather than the bin shim, and is executable.
